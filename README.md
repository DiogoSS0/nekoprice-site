# NekoPrice Web

Public static frontend for NekoPrice.

- Website: https://diogoss0.github.io/nekoprice-site/
- Catalogue API: https://diogosasa.pythonanywhere.com/
- Full source code: private repository `DiogoSS0/nekoprice-source`

This repository intentionally contains only the browser application and public
assets. Backend code, credentials, databases, logs, checkpoints, recovery
queues, and deployment tooling are not published here.

The site is deployed from the `main` branch with GitHub Pages.
